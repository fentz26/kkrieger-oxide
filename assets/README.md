# Source data

`kkrieger3383.kx` is the unchanged published development export from
`farbrausch/fr_public`, commit `8c8f82c2ae01133370e649bbc05916e7aceecadd`, path
`werkkzeug3_kkrieger/data/kkrieger3383.kx`.

SHA-256: `f96af47de9558161b3203240af412c8050a574d2b72ac56323e7bb69554fcac6`.

It is covered by the accompanying Farbrausch BSD license in
`third_party/farbrausch-LICENSE.txt`. It is later development data, not the
Breakpoint 2004 release export. It is currently used to validate the Rust
decoder and operator port; it is not embedded in the prototype executable.

The exact 2004 release export has also been independently extracted locally
from scene.org's unchanged original release archive using a bounded x86
emulator. It is retained as `.reference/verified-beta.kx` for port validation.
Its SHA-256 is
`503c9cda010801a5df95928574f2b9abf40f270396444a2ac79a5c5f233bf0c2`.
It matches the export published by MasonDye's port byte for byte.
The release archive is freeware with separate distribution terms; it and its
extracted data are not relicensed as MIT or BSD by this project.
